# Noto Sans Japanese

Fuentes originales de Noto CJK, versión `Sans2.004`, incluidas para que los PDF
en japonés mantengan texto seleccionable y no dependan de fuentes del servidor.

- Regular: https://github.com/notofonts/noto-cjk/blob/Sans2.004/Sans/SubsetOTF/JP/NotoSansJP-Regular.otf
- Bold: https://github.com/notofonts/noto-cjk/blob/Sans2.004/Sans/SubsetOTF/JP/NotoSansJP-Bold.otf
- Licencia original: https://github.com/notofonts/noto-cjk/blob/Sans2.004/LICENSE

Se distribuyen sin modificar bajo la SIL Open Font License 1.1, copiada en
`LICENSE.txt`. El renderizador las utiliza sólo en documentos japoneses.
