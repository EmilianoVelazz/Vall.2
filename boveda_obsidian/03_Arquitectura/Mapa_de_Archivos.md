# 📂 Mapa de Archivos y Carpetas

Este documento sirve como el índice maestro de cómo está organizado tu proyecto en el disco duro.

## 📁 Directorios Principales

- **`/api/`**: Endpoints principales de la API (Backend en JS/Node).
- **`/api_Gemini/`**: Módulo específico para la IA y Google Gemini (Entorno Python/JS).
- **`/assets/`**: Recursos estáticos: Hojas de estilo CSS (mucha UI personalizada), scripts JS e imágenes.
- **`/scripts/`**: Scripts de automatización y utilidades (bash, node, etc).
- **`/docs/`**: Documentación del repositorio.
- **`/frontend/`**: Lógica visual, vistas y componentes.
- **`/backend/`**: Lógica fuerte del servidor y bases de datos.

## 📄 Archivos Raíz Clave

- **`package.json`**: Dependencias de Node.js.
- **`vercel.json`**: Configuración de despliegue (Vercel).
- **`index.html`**: Punto de entrada principal web.
- **`inicio.html`**: Vista alternativa o dashboard inicial.
