# Generación Aumentada por Recuperación (RAG)

Conectar nuestra base de datos con Gemini mediante Bases de Datos Vectoriales (Embeddings). Esto permite que la IA "hable" con nuestros datos reales sin tener que reentrenarla cada día. Un avance masivo para la [[Escalabilidad_Base_de_Datos]].
